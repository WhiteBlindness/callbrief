# Perfil de exemplo

Este é um perfil fictício, criado apenas para os testes e a demonstração.

A Maré Labs é uma pequena e média empresa portuguesa, sediada em Braga, com
14 trabalhadores. Desenvolve protótipos para mobilidade de baixas emissões.

O perfil não indica se a empresa dispõe de fundos próprios para cofinanciar um
projeto.
